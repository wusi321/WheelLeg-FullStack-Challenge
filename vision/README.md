# 视觉感知与视觉闭环题目（20 分）

视觉系统可以使用 USB/CSI 摄像头或仿真相机，至少完成图像采集、标定/坐标说明，以及目标检测、地面/障碍物识别或落脚区域判断中的一项，并将结果用于展示、避障、落脚、速度限制或安全策略。核心控制仍须由 C++ 控制器完成。

必须明确分辨率、帧率、视场角、安装位姿、坐标系、内参/畸变、Topic、QoS 和延迟。没有实体硬件时，可用 Gazebo 相机、录制数据集或 rosbag，但需说明与实体部署的差异。

## 交付物

提交视觉 ROS 2 节点、配置、启动文件、模型权重或下载说明、标定文件、测试数据、可视化结果和性能记录。至少提供一段实时或 rosbag 演示，包含原图、识别结果和控制器使用结果，并记录平均延迟、帧率和精度指标或人工验收方法。

## 评分

| 项目 | 分值 |
| --- | ---: |
| 相机/仿真相机接入、标定、坐标系和权限 | 4 |
| ROS 2 图像 Topic、消息、QoS 和节点工程 | 3 |
| 视觉算法实现与数据/模型说明 | 5 |
| 目标、地面/障碍物或落脚区域识别效果 | 3 |
| 视觉结果接入 C++ 控制器并形成安全闭环 | 3 |
| 实时性能、异常处理和测试证据 | 2 |

合计 20 分。只有静态截图、没有输入输出链路或没有失败策略的演示不能获得对应闭环分数。
