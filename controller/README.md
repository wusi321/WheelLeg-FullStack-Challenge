# C++ 控制器题目（10 分）

## 题目说明

使用 C++（建议 C++17）实现 ROS 2 控制节点和可复用 Controller API。核心逻辑不得用 Python 替代。建议拆分控制器、运动学、动力学、平衡和轨迹规划模块，输入用户指令和机器人状态，输出关节/轮目标。

## 交付物

`include/`、`src/`、`config/`、`launch/`、`CMakeLists.txt`，接口说明和单元/集成测试。应包含逆运动学、轮腿协调、跳跃轨迹、限位与异常处理。

## 评分

| 项目 | 分值 |
| --- | ---: |
| C++ ROS 2 Node | 2 |
| 控制器分层与接口架构 | 2 |
| 运动学/动力学计算 | 2 |
| 轨迹规划（含跳跃） | 2 |
| 控制稳定性、限位和故障处理 | 2 |

## 验收

检查源码、编译日志、Topic/参数接口和仿真效果；Python 仅可用于数据分析、绘图、数据集处理或自动化测试。
