# C++ 控制器题目（10 分）

## 题目说明

使用 C++（建议 C++17）实现 ROS 2 控制节点和可复用 Controller API。核心逻辑不得用 Python 替代。建议拆分控制器、运动学、动力学、平衡和轨迹规划模块，输入用户指令和机器人状态，输出 6 个电机的关节/轮目标。控制输入必须订阅 [`docs/remote_control.md`](../docs/remote_control.md) 约定的 Topic，支持键盘、模拟 Web 或 CAN 网关输入。

控制部署必须明确选择一种模式：

- **纯上位机**：上位机直接通过 GPIO 外设或 USB-CAN 模块发送 CAN 帧，完成 6 电机控制。
- **上下位机联合**：上位机接收遥控器、IMU/状态等数据，通过 GPIO、USB-TTL 或其他串行链路向下位机发送高层命令；下位机解析命令并负责 CAN 电机控制。
- **纯下位机**：不依赖上位机，遥控器/传感器、控制算法和 CAN 执行链路全部在下位机闭环；可将仿真或虚拟执行器部署到下位机进行演示。

三种模式都必须给出数据流、故障/急停策略和可重复的演示方式。纯下位机方案完成度完整时，可按 `linux/README.md` 约定获得 Linux 控制链路部分分数。

## 交付物

`include/`、`src/`、`config/`、`launch/`、`CMakeLists.txt`，接口说明和单元/集成测试。应包含逆运动学、轮腿协调、跳跃轨迹、限位与异常处理；同时提交上位机/下位机模式选择、链路时序和 6 电机映射表。

## 验收

检查源码、编译日志、Topic/参数接口、6 电机目标和仿真效果；验证遥控输入 200 ms 超时后的安全行为。Python 仅可用于数据分析、绘图、数据集处理或自动化测试。
