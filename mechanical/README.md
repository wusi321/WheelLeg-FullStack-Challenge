# 机械结构与 CAD 题目（15 分）

## 题目说明

设计双轮、左右四连杆腿的机器人机械结构。使用 SolidWorks、Fusion 360、Creo、FreeCAD 或其他可导出标准三维模型的 CAD 软件，完成装配体、关键零件、四连杆、左右轮、机身、电机安装位、关节连接和关键尺寸图。

必须说明总长、总宽、总高、轮径、轮距、连杆长度、关节间距、最大/最小腿展、材料和质量来源；各刚体不得全部使用 1 kg，惯量必须由 CAD/材料计算或提供完整 `ixx/iyy/izz/ixy/ixz/iyz`。

## 交付物

`CAD/Assembly/`、`CAD/Parts/`、`CAD/Drawing/`、`STEP/`、参数表和本目录说明。装配体应能解释运动范围、限位和电机安装方式，并可与 `robot_description/` 对照。

## 验收

展示 CAD→装配体→四连杆运动；抽查尺寸、质量和惯量，并检查与 URDF 的一致性。
