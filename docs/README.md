# 工程文档题目（5 分）

## 题目说明

文档必须让他人能够理解设计决策、复现环境、运行仿真、联调 CAN 并追溯开发过程。至少维护总体需求、系统架构、坐标系、CAN 协议和开发记录；文档中的参数、接口和代码必须保持一致。

## 交付物

`requirements.md`、`architecture.md`、`coordinate_system.md`、`can_protocol.md`、`development_log.md`，以及最终演示步骤、故障处理和已知限制说明。

## 评分

| 项目 | 分值 |
| --- | ---: |
| 需求覆盖完整、结构清晰 | 1 |
| 架构、坐标系和接口说明 | 1 |
| CAN 协议可实现且与代码一致 | 1 |
| 构建、运行、测试和演示步骤 | 1 |
| 开发记录、限制和可维护性 | 1 |
